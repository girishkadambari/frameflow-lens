# Frameflow Studio

Build a premium, production-ready frontend for an AI Film Production Intelligence platform called "FRAMEFLOW".

IMPORTANT:

This is a visual/product design and frontend implementation task.

Build the COMPLETE PRODUCT EXPERIENCE and all major UI flows with realistic demo data.

Do NOT build this as a generic SaaS admin dashboard.

Do NOT make it look like a generic AI image generator.

Do NOT use the sample story from any external specification.

Use fictional demo production data throughout the interface.

The product should feel like a real startup product that can be demonstrated to film studios, directors, production companies, VFX teams, AI filmmaking teams and investors.

==================================================

1. PRODUCT CONCEPT

==================================================

FRAMEFLOW is an AI Film Production Intelligence platform.

The core idea is:

Production Asset =

Identity + State + Relationships + References + Constraints + History

The AI models are rendering/reasoning engines.

FRAMEFLOW is the intelligence layer that understands:

- Projects

- Characters

- Locations

- Rooms

- Props
